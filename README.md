# People. User Directory

A simple React user management app built for practicing API calls, `useEffect`, Zustand, and localStorage.

## Features

- Fetches users from JSONPlaceholder with `useEffect`
- Shows loading, error, empty, search, and favorites states
- Opens a details modal for each user
- Saves favorite users in localStorage through Zustand `persist`
- Responsive card layout for desktop and mobile

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy on Vercel

1. Push this folder to a public GitHub repository.
2. Import the repository at [vercel.com/new](https://vercel.com/new).
3. Keep the default Vite settings and click **Deploy**.
4. Add the live Vercel URL to this README before submission.

## Stack

React, Vite, Zustand, Lucide React, and the JSONPlaceholder API.
